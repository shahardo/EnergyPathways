# `lib/db/`

Drizzle ORM schema and queries over `better-sqlite3` (SPEC §6.1–6.2, DEV-PLAN T4).

| File          | Purpose                                                                                                                    |
| :------------ | :------------------------------------------------------------------------------------------------------------------------- |
| `schema.ts`   | The 14 tables (value tables + layout metadata) as Drizzle `sqliteTable`s                                                   |
| `client.ts`   | `getDb()` — opens `db/reference.sqlite`, runs migrations, hydrates from `db/snapshot.json` when the DB is missing or stale |
| `snapshot.ts` | Reads + Zod-validates `db/snapshot.json`                                                                                   |
| `hydrate.ts`  | Loads a validated snapshot into the (migrated) tables                                                                      |
| `queries.ts`  | `getWorkbookPayload()` and `getChannel(id)` — assemble rows back into the `lib/schemas/workbook.ts` shapes, Zod-validated  |

`reference.sqlite` is gitignored and disposable: delete it any time and the
next call to `getDb()` rebuilds it from the committed `db/snapshot.json`
(no OOXML parsing needed). To regenerate the snapshot itself from the
source workbook, run `npm run ingest` (see `scripts/ingest-workbook.ts`).

Schema migrations live in `../../drizzle/` (committed, generated by
`npx drizzle-kit generate` after any `schema.ts` change).
